# Global AI Adoption in Education

## Project Overview

This project analyzes global AI adoption in education using Tableau.

The dataset contains 1,360 records and 16 columns, covering monthly observations from January 2015 to December 2026 across 10 countries and 6 global regions.

## Tools Used

- Tableau Public
- Data Analytics
- Data Visualization
- Excel/CSV
- GitHub

## Dashboards

### Dashboard 1
Global AI Adoption in Education

- AI Adoption Journey
- Global Internet Access Comparison

### Dashboard 2
Global AI Project: Adoption, Usage, and Growth

Includes:
- Country-Level AI Adoption

- Leading AI Tools
- Rural vs Urban AI Usage

## Tableau Story

The project contains 7 story scenes:

1. Global AI in Education Challenge
2. Geographic Disparity
3. AI Adoption Journey (2015–2026)
4. Leading AI Platforms
5. Digital Equity: Urban vs Rural
6. Student vs Teacher Adoption
7. Conclusions and Recommendations

## Key Findings

- AI adoption increased significantly between 2015 and 2026.
- Urban AI usage is higher than rural AI usage.
- Student and teacher AI usage rates are relatively similar.
- ChatGPT, Microsoft Copilot, Google Gemini, and Khanmigo have competitive market shares.

## Dataset

- Rows: 1,360
- Columns: 16
- Countries: 10
- Regions: 6
- Period: 2015–2026
